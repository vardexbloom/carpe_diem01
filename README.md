# Carpe Diem

Next.js 16 storefront (App Router, JavaScript, plain CSS) with Supabase and Cashfree.

    npm install
    npm run dev      # http://localhost:3000
    npm run lint
    npm run build

Database, checkout and payments: see **SETUP.md**. Edit contact details in `app/data/site.js`.
Needs Node 20.9 or newer (Node 22 LTS recommended).
SQL tests for the database rules are in `supabase/tests/`.
